# Abdelrahman Waleed — Portfolio

A bilingual (English / Arabic) one-page portfolio for **Abdelrahman Waleed** — WordPress developer based in Suez, Egypt.

Live: **https://abdelrahman-w.github.io/portfolio/**

## What's inside

- `index.html` — markup, CSS, and JavaScript in one page. No build step, no dependencies, no tracking.
- `assets/` — optimized screenshots used in the selected client-work cards.
- Instant **EN ⇄ AR** switching with full RTL layout, driven by an in-page `i18n` dictionary.
- **Dark / light** themes; both preferences persist in `localStorage`.
- Refined modern color system: luminous slate surfaces (`#F8FAFC`), deep obsidian dark mode (`#0B0F19`), electric blue interaction tokens (`#2563EB` / `#38BDF8`), and live uptime indicators (`#10B981`).
- Subtle scroll reveals respect `prefers-reduced-motion`.
- Print styles so the page exports cleanly to PDF as a CV.
- Fonts loaded from Google Fonts: Manrope, DM Sans, IBM Plex Sans Arabic.

## Sections

Hero (with live client sites) · Selected work · Services · Background & experience · Contact

## Editing

Everything lives in `index.html`. Text content is addressed by `data-i18n` keys — update the `I18N` object near the top of the `<script>` block (both `en` and `ar`) to change copy in either language.
